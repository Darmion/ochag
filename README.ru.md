# Очаг

[English version](README.md)

«Очаг» — виртуальный стол для фэнтезийных ролевых игр по правилам пятой редакции. Мастер запускает сервер на своём компьютере с Windows. Игроки подключаются по домашней или виртуальной локальной сети или через интернет — туннелем Cloudflare или по белому IP-адресу мастера. Интерфейс — на русском и английском.

Проект в открытой бете.

## Возможности

- **Стол.** Сцены на трёхмерном поле: фигуры, стены, двери, туман войны, свет, погода, музыка и звуки. Игроки могут подключаться и с телефона, через браузер.
- **Правила.** Сервер сам применяет правила пятой редакции из SRD 5.1: инициативу и очередь хода, экономию действий, атаки и урон, состояния, заклинания с целями и областями, спасброски, реакции, укрытие, умения классов и рас, отдых, опыт и уровни. Ход НПС можно сыграть одной кнопкой.
- **Персонажи.** Пошаговое создание, новые уровни, мультикласс, снаряжение, магические предметы и свои заклинания.
- **Кампании.** Задания, хроника, раздаточные материалы, лавки, встречи, бестиарий и мини-игры.
- **Сервер.** Аккаунты, приглашения, резервные копии по расписанию, перенос кампании на другой компьютер, раздача обновлений игрокам с сервера мастера.
- **Моды.** Моды правил ставит мастер, и они главнее встроенных правил. Моды оформления каждый игрок ставит себе. Подробнее — в [docs/MODS.md](docs/MODS.md).

## Как начать

1. Скачайте `Ochag-Setup-<версия>.exe` со [страницы Releases](https://github.com/Darmion/ochag/releases) и запустите. Установщик не подписан, поэтому Windows может показать «Windows защитил ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
2. **Мастер.** Выберите «Я мастер». Сервер запустится на вашем компьютере, база данных встроена. Ей нужен компонент Microsoft Visual C++ Redistributable (x64), который есть на большинстве компьютеров; если его нет, приложение скажет об этом и предложит скачать его с сайта Microsoft. Создайте кампанию и отправьте игрокам приглашение. Для игроков не из вашей сети откройте вкладку «Сервер» → «Игроки через интернет».
3. **Игрок.** Выберите «Я игрок» и вставьте приглашение от мастера. Чтобы играть с телефона, откройте в браузере адрес мастера с `/phone/` на конце.

## Сборка из исходников

Нужны Windows, Node.js 24 или новее и Docker Desktop для базы данных разработки.

```powershell
Copy-Item .env.example .env       # впишите POSTGRES_PASSWORD и APP_DB_PASSWORD (не короче 20 символов)
docker compose up -d --wait
npm ci
npm --prefix apps/client ci
npm run db:migrate
npm run db:provision
npm start                         # сервер API на http://127.0.0.1:3000
```

Во втором окне — клиент в браузере, который проксирует запросы на этот сервер:

```powershell
npm --prefix apps/client run dev  # http://127.0.0.1:5173
```

Настольное приложение само запускает встроенный PostgreSQL и сервер, Docker ему не нужен:

```powershell
npm run desktop                   # собрать клиент и открыть его в Electron
npm run desktop:dist              # собрать установщик в release/
```

Проверки:

```powershell
npm run typecheck
npm --prefix apps/client exec vue-tsc -- -b
npm test                          # PostgreSQL в памяти, вашу базу не трогает
npm run i18n:check                # у каждой строки интерфейса есть английский
```

Те же проверки GitHub запускает при каждой отправке и каждом запросе на слияние (`.github/workflows/ci.yml`).

## Устройство репозитория

| Путь | Что там |
|---|---|
| `apps/server` | API на Fastify и WebSocket `/live`; сервер — источник истины и проверяет все права |
| `apps/client` | Клиент на Vue 3 и TypeScript; трёхмерный стол — на Babylon.js |
| `apps/desktop` | Оболочка Electron: встроенный PostgreSQL и сервер, изолированное окно и ограниченный API preload |
| `packages/domain` | Правила игры без сервера и базы и данные SRD 5.1 |
| `packages/importer` | Общий формат листа персонажа для модов импорта |
| `mods` | Отключаемые моды в комплекте: набор картинок и импорт листов Long Story Short |
| `examples/mods` | Примеры модов |
| `db` | SQL-миграции и проверки схемы |
| `scripts` | Миграции, резервные копии, сбор строк для перевода, сборка |
